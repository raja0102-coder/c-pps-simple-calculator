# PPS Simple Calculator Engine

A beginner-level Semester 1 Programming for Problem Solving (PPS) C application implementing a command-line calculator.

## PPS Concepts Covered
* **Control Flow**: `switch-case` decision structures and `while` loop iterations.
* **Input / Output Handling**: Standard stream reading via `scanf` and formatted printing via `printf`.
* **Arithmetic Operations**: Fundamental operations including addition, subtraction, multiplication, real division, and integer modulus.
* **Boundary Checks**: Division-by-zero validation.

## How to Compile & Run
```bash
gcc main.c -o calculator
./calculator
